2. Shopify Custom App Setup & Permissions

To automate collections, menus, and stock via Shopify GraphQL Admin API, create a private Custom App with these permissions:

  1. Log in to your Shopify Admin.
  2. Go to Settings > Apps and sales channels.
  3. Click Develop apps (or Allow custom app development) > Create an app.
  4. Name the app: Shopify Flow Manager.
  5. Click Configure Admin API scopes and select these scopes:

Mandatory Admin API Scopes:

1. Smart Collections & Sales Channels (Auto-Publish):
read_products write_products read_publications write_publications

2. 3-Tier Mega Menu & Navigation:
read_online_store_navigation write_online_store_navigation

3. Bulk SKU Generator & Inventory Sync:
read_inventory write_inventory

  1. Click Save, then click Install app.
  2. Copy the revealed Admin API access token (starts with shpat_...) and paste it into the extension popup.

3. Universal Multi-AI Engine Setup

Connect your preferred AI provider directly. Your API keys are stored strictly in your local browser:

  • Google Gemini (Recommended & 100% Free): Get your free API key at aistudio.google.com (No credit card required).
  • OpenAI (ChatGPT / GPT-4o): Create an API key at platform.openai.com/api-keys.
  • Groq (Ultra-Fast): Generate your key at console.groq.com.
  • DeepSeek (V3 / R1): Get your key from platform.deepseek.com.
